# 地鐵衝刺 (Subway Runner)

一個使用 HTML5 Canvas 開發的跑酷遊戲。

## 遊戲功能

### 操作方式
- **← / →** 或 **A / D** - 切換軌道
- **↑ / W / 空白鍵** - 跳躍

### 遊戲玩法
- 玩家在一條有 3 條軌道的道路上奔跑
- 躲避障礙物（火車、欄杆）
- 收集金幣獲得額外分數
- 隨著分數增加，遊戲速度會越來越快
- 最高分會保存在 localStorage 中

### 遊戲特色
- 3 條平行軌道設計
- 兩種障礙物類型：火車、欄杆
- 金幣收集系統（+50 分）
- 障礙物通過得分（+10 分）
- 跳躍功能可越過低矮障礙
- 粒子特效系統
- 本地最高分儲存

## 技術規格
- 單一 HTML 檔案，無需外部依賴
- 使用 Canvas API 繪製圖形
- 使用 localStorage 儲存最高分數
